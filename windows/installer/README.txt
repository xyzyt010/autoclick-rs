AutoClick-RS
============

Cross-platform automatic key presser with a clean GUI.

Features:
- Send keystrokes to any window without focus steal
- Multiple injection modes (Window / Screen)
- Terminal and GUI app detection
- Configurable key sequences and intervals
- Hotkey support

Installation:
  Run the setup wizard and follow the prompts.

Uninstallation:
  Use Windows Settings > Apps > AutoClick-RS, or run Uninstall.exe.
